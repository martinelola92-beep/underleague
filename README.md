# Underleague

Roguelite de gestión y autobatalla con equipos de fútbol 7 formados por criaturas fantásticas. Partidos de 60-90 segundos que se juegan solos; decisiones entre partidos; plantillas que se lesionan, mueren y se reconstruyen con prótesis.

- Plataforma: PC (Steam), premium, sin online.
- Stack: Godot 4.6 .NET, C#, simulador determinista independiente del motor.
- Estado: preproducción, fase 0.

Documentación en [`docs/`](docs/README.md). Requisitos completos en [`docs/requisitos.md`](docs/requisitos.md). Guía de trabajo con Claude Code en [`CLAUDE.md`](CLAUDE.md).
