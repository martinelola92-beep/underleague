# BA-F — El 3D está mal.

**Estado:** Abierta

## Observación

**El 3D está mal.** «No veo a los porteros en pantalla. Sigo viendo el grid como si fuera en 2D.» Referencia pedida: **cámara estilo FIFA**, con perspectiva perceptible; si hace falta, 2D de fondo para simular movimiento

## Análisis / estado actual

**Abierta.** Contradice en parte la ADR 0102, que eligió **ortográfica** para que la casilla mida igual en todo el campo. Hay que decidir si se acepta perspectiva y con ella la distorsión de distancias
